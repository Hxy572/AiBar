# AIbar 界面整合

针对手机触屏操作优化，电脑端也可用。

## 功能
- 原生动作条替换
- 背包整合（商店/邮箱/交易时自动打开）
- 职业资源监控
- 施法条替换
- 单手武器可在物品菜单里直接装到副手
- 消耗品用光后动作条图标变暗；堆叠数量加粗

## 安装
把 `AIbar/` 整个目录放进客户端 `Interface/AddOns/` 下，重载界面。
（目录名必须是 `AIbar`，与 `AIbar.toc` 文件名一致）

## 命令
| 命令 | 作用 |
|---|---|
| `/ab` | 打开配置面板 |
| `/abc move` | 移动模式开/关 |
| `/abc save` | 存档自检 |
| `/abc pc` | 平台模式：自动 / 电脑 / 触屏 |
| `/abc chatbar` | 聊天快捷按钮开/关 |
| `/abc help` | 全部命令 |
