# AIbar

魔兽世界 1.12 手机客户端的触屏动作条，界面全自绘。

**版本 1.48**

## 功能

- 动作条：12 格/页，共 7 页，从下往上排，潜行自动第 7 页；四态染色、冷却扇形+数字、点空格换技能
- 资源面板：能量、连击点、自身/目标/宠物、碎片、平砍计时
- 施法条：自己/目标两条，可调宽高、反转、预览、锁定、职业色
- 背包整合：背包+4 包一屏显示，分类/背包筛选，整理，钥匙栏，拿起放下交换，商店出售模式
- 模块开关：任意模块关掉即还原原生界面

## 安装

1. 下载 Release 里的 `AiBar.zip`
2. 导入到 `Interface/AddOns/`
3. 完全重启游戏，进游戏点「配置」或输入 `/ab`

## 命令

`/ab` 配置面板　`/abc move` 移动模式　`/abc diag` 诊断　`/bag` 背包
