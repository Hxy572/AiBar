# AIbar 触屏动作条

魔兽 1.12（Interface 11200）插件，针对手机触屏操作优化，电脑端也可用。

## 功能
- 动作条 7 页、潜行第 7 页，四态染色（射程/资源/不可用/终结技）
- 点空格开技能选择器，右键或长按换技能
- 背板、资源面板、施法条、职业栏、宠物条
- 背包整合：分类、品质筛选、整理、钥匙栏、出售模式
- 配置面板 `/ab`；`/abc help` 查看命令
- 存档自动写三处（账号/角色/镜像表），换设备不丢
- 电脑端自动识别，按钮和把手自动缩小

## 安装
把 `aibar/` 整个目录放进客户端 `Interface/AddOns/` 下，重载界面。
（目录名必须是 `aibar`，与 toc 文件名一致）

## 命令
| 命令 | 作用 |
|---|---|
| `/ab` | 打开配置面板 |
| `/abc move` | 移动模式开/关 |
| `/abc save` | 存档自检 |
| `/abc pc` | 平台模式：自动 / 电脑 / 触屏 |
| `/abc help` | 全部命令 |

## 说明
- 触摸客户端没有 `os` 库，代码里只用 `string`/`math`/`table`/`pcall`
- 安卓客户端切潜行页时客户端自身会卡 2~4 秒，与插件无关
