# AIbar

针对手机触屏操作优化，电脑端也可用。当前版本 **1.0.4**，界面支持中 / 英双语。

## 功能
- 原生动作条替换；
- 技能 / 宏 / 物品选择器；
- 职业资源监控
- 施法条替换（自己 / 目标）、
- 聊天快捷按钮、目标职业标记

## 安装
把 `AIbar/` 整个目录放进客户端 `Interface/AddOns/` 下，重载界面。
（目录名必须是 `AIbar`，与 `AIbar.toc` 文件名一致）

## 命令
| 命令 | 作用 |
|---|---|
| `/ab` | 打开配置面板 |
| `/abc move` | 移动模式开/关 |
| `/abc lock` | 技能锁定开/关 |
| `/abc lang` | 界面语言：zh / en / auto |
| `/abc save` | 存档自检 |
| `/abc pc` | 平台模式：自动 / 电脑 / 触屏 |
| `/abc chatbar` | 聊天快捷按钮开/关 |
| `/abc help` | 全部命令 |
