# AIbar · 触屏动作条（WoW 1.12 / 手机客户端）

为「Azeroth」手机客户端重写的触屏动作条，界面全自绘，不依赖原生动作条。

## 功能

- **动作条**：12 格 / 页，共 7 页；潜行自动切第 7 页；四态染色（可用 / 缺资源 / 不可用 / 超距）；冷却扇形 + 数字；长按换技能，点空格选技能/宏/物品
- **资源面板**：能量/法力、连击点、自身/目标/宠物、灵魂碎片、平砍计时（按实际攻速滚动平均）
- **施法条**：自己/目标两条，宽高独立、反转、预览、锁定、职业色；隐藏原生施法条
- **背包整合**：背包+4包一次铺满，「背包」「分类」两个下拉筛选；品质圆点；整理（品质→名称）；钥匙栏；拿起/放下/交换；商店里的出售模式
- **模块开关**：动作条 / 资源条 / 施法条 / 背包 / 辅助按钮 / 职业栏，关掉即还原原生
- **其他**：屏蔽装备耐久弹窗、原生背包图标钉死、面板微调（方向键 2px）

## 安装

1. 下载 `AIbar.zip`（Release 里）
2. 在游戏里导入这个压缩包到 `Interface/AddOns/`
3. **完全重启游戏**（不是 /reload）
4. 进游戏点屏幕上的「配置」，或输入 `/ab`

## 命令

| 命令 | 作用 |
|---|---|
| `/ab` | 打开配置面板 |
| `/abc move` | 开关移动模式 |
| `/abc skin` | 开关背板 |
| `/abc diag` | 输出诊断信息 |
| `/abc macro` | 检查客户端宏接口 |
| `/bag` | 开关背包 |
