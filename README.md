# AIbar 界面整合

针对手机触屏操作优化，电脑端也可用。

## 功能
- 原生动作条替换（可关：模块页「动作条」，关掉后还原客户端原生布局，我们的存档保留）
- 背包整合：商店 / 邮箱 / 交易 / 拍卖行自动打开；原生背包窗口不重复弹出
- 背包整理：先合并同类堆叠，再按 品质 / 分类 / 顺序 / 等级 排序，支持反序（从最后一格往前放）
- 背包设置：图标大小、行列数、整理方式
- 职业资源监控（每条可选显示数字，字号随条高）
- 施法条替换（自己 / 目标）
- 单手武器可装副手；主手/副手/护盾/法球/魔典/魔杖/圣物/弹药按装备位自动放对栏位
- 物品菜单按客户端数据自动判断「使用 / 装备 / 材料」
- 点击闪光（动作条、职业条、跳、目、背包格子）
- 目标头像显示玩家职业（职业色文字，NPC/怪物不显示，位置可调）
- 聊天快捷按钮（说/喊/会/队/团/本/世/组/骰），可随聊天框显隐、可调位置
- 消耗品用光后图标变暗；堆叠数量加粗
- 小地图旁的配置按钮，随时可拖

## 安装
把 `AIbar/` 整个目录放进客户端 `Interface/AddOns/` 下，重载界面。
（目录名必须是 `AIbar`，与 `AIbar.toc` 文件名一致）

## 命令
| 命令 | 作用 |
|---|---|
| `/ab` | 打开配置面板 |
| `/abc move` | 移动模式开/关 |
| `/abc save` | 存档自检 |
| `/abc pc` | 平台模式：自动 / 电脑 / 触屏 |
| `/abc chatbar` | 聊天快捷按钮开/关 |
| `/abc help` | 全部命令 |
